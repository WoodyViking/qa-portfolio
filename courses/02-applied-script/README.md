## Kursens innehåll

Kursen bygger vidare på programmeringen: att skripta och skriva serier av kommandon med inriktning på IT-test, att konfigurera nätverksmiljöer och nätverksenheter med skript, och att automatisera repetitiva eller komplexa uppgifter med skript och SQL.

**Huvudsakliga moment**

- Introduktion till skriptning och kommandostrukturer
- SQL för automatisering
- Nätverksmiljöer och ISTQB
- Konfigurera nätverksmiljöer med skript
- Kommandokedjor: längre skript för specifika uppgifter

## Läranderesultat (ur kursplanen, förkortat)

**Kunskaper**

- Testprinciper och deras praktiska tillämpning
- Skillnader mellan testnivåer och testtekniker
- Metoder för testautomatisering

**Färdigheter**

- Planera, genomföra och analysera tester med verktyg och metoder
- Skapa och köra automatiserade tester för olika scenarier
- Testa enligt standarder som ISTQB

**Kompetens**

- Självständigt planera och genomföra tester i projekt
- Arbeta med testautomatisering
- Bidra till bättre testprocesser
